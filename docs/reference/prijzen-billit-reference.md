# Prijzenpagina — Billit light referentie

Bron: Firecrawl scrape van https://www.billit.eu/nl-be/prijzen/ (jul 2026).

## Layout (light mode)

1. **Hero** — lichte achtergrond, kicker + H1 + introtekst + social proof
2. **Billing toggle** — jaarlijks / maandelijks / per kwartaal (pill-tabs)
3. **Prijskaarten** — 4 kolommen, documentlimiet als kop, doorgestreepte + actuele prijs, CTA, “Alle functies inbegrepen”
4. **Goed om te weten** — bulletlijst met praktische info
5. **Features** — checklist “Alles wat je nodig hebt…”
6. **FAQ** — accordion
7. **CTA-blok** — gratis proefperiode

## Billit kleuren (light)

| Token | Hex | Gebruik |
|-------|-----|---------|
| Achtergrond | `#FFFFFF` | Pagina |
| Tekst | `#004B70` | Koppen, body |
| Primair (CTA) | `#F29531` | Oranje knoppen |
| Secundair | `#6493AA` | Accenten |
| Secundaire knop bg | `#FDF3E7` | Licht oranje vlak |
