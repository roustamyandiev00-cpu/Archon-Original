# Dashboard light mode — Billit referentie

Bron: Firecrawl branding van [Billit login/dashboard](https://my.billit.eu/Home/Dashboard) (login vereist voor volledige UI).

## Billit app light tokens

| Token | Hex | Gebruik |
|-------|-----|---------|
| Achtergrond | `#FFFFFF` | Hoofdvlak |
| Pagina-bg | `#F5F6F8` | Subtiele zone |
| Tekst | `#212529` | Body |
| Secundair | `#6C757D` | Labels |
| Rand | `#CED4DA` | Inputs, cards |
| Primair | `#F06F00` | CTA (Billit oranje) |

## ArchonPro mapping

| Billit | ArchonPro light |
|--------|-----------------|
| Oranje primair | Blauw `#3B82F6` |
| Wit/grijs content | `--dash-bg` / `--dash-surface` |
| Donkere nav | Sidebar `#151921` (blijft donker, iets lichter) |

Dark mode (`data-theme="dark"`) blijft ongewijzigd.
