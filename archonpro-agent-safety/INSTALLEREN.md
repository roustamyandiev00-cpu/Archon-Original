# Installeren in ArchonPro

Plaats de inhoud van deze map in de hoofdmap van je ArchonPro-repository.

Na het kopiëren moet de repository deze bestanden bevatten:

- `AGENTS.md`
- `WORKFLOW.md`
- `.cursor/rules/archonpro-safety.mdc`
- `.kiro/steering/archonpro-safety.md`

De `.cursor`- en `.kiro`-mappen kunnen verborgen zijn in Finder. Zet indien nodig de weergave van verborgen bestanden aan.

Start daarna Cursor of Kiro opnieuw en geef eerst alleen deze opdracht:

> Lees AGENTS.md en bevestig welke regels je bij alle volgende wijzigingen zult toepassen. Wijzig nog geen bestanden.

Laat vervolgens de agent de bestaande repository inventariseren. Laat hem nog niets opruimen of verplaatsen voordat je het inventarisrapport hebt bekeken.
